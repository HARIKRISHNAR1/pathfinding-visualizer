PATHFINDING VISUALIZER

The pathfinding visualizer mainly focuses on solving the gap between theory and practical experience.
The concept of BFS, DFS and A* are visually represented.

TECH STACK
- HTML
- CSS
- JAVASCRIPT
- PYTHON (FLASK)
- VISUAL STUDIO CODE
- GIT & GITHUB
- WINDOWS TERMINAL

KEY FEATURE:
- NODES ARE REPRESENTED AS CIRCLE
- GREEN COLOR IN NODE REPRESENT START NODE & RED COLOUR REPRESENT STOP
- BLUE - VISITED , BLACK - WALLS/INACTIVE NODE , YELLOW - PATH
- Bridges the gap b/w theory and practicle(visual representation easy to understand concept)

HOW TO RUN LOCALLY
- Download the folder
- Install flask , command - pip3 install flask
- Run app.py file which is inside of the folder
- open web browser and go to  http://127.0.0.1:5000
- Perform different operations in the software.
